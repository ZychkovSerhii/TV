# ТВ Пульт — керування Google TV з телефона через Bluetooth

Телефон представляється телевізору як бездротова клавіатура + пульт (Bluetooth HID).
Перевірено під: TCL 55V6B (Google TV) + OnePlus 10T. Працює з будь-яким Android 9+
і телевізорами/приставками на Android TV / Google TV.

## Що вміє
- Стрілки, OK, Назад, Додому, Меню, Пошук (Асистент)
- Гучність +/−, вимкнення звуку
- Відтворення/пауза, попередній/наступний
- Живлення (лише вимкнути — увімкнути ТВ по Bluetooth неможливо, коли він вимкнений)
- Введення тексту латиницею в пошук на ТВ
- Утримання кнопки працює як на звичайному пульті (прокрутка, гучність)
- Запам'ятовує телевізор і підключається сам при запуску

## Як зібрати APK

### Варіант А — Android Studio (Windows)
1. Встановіть Android Studio: https://developer.android.com/studio
2. File → Open → оберіть папку `TvRemote`. Зачекайте, поки Gradle завантажить усе потрібне (перший раз 5–10 хв).
3. Build → Build App Bundle(s) / APK(s) → Build APK(s).
4. Готовий файл: `app\build\outputs\apk\debug\app-debug.apk`.

### Варіант Б — без Android Studio, через GitHub
1. Створіть репозиторій на github.com і завантажте туди вміст папки `TvRemote`.
2. Вкладка Actions → збірка «Build APK» запуститься сама (~4 хв).
3. Відкрийте завершений запуск → Artifacts → `TvRemote-apk` → скачайте APK.

## Як встановити на OnePlus 10T
1. Перекиньте `app-debug.apk` на телефон (кабель, Telegram «Збережене», Google Drive).
2. Відкрийте файл → дозвольте встановлення з цього джерела → Встановити.
3. Запустіть «ТВ Пульт» і дозвольте доступ до «Пристроїв поблизу».

## Перше сполучення з телевізором
1. Якщо телефон уже був сполучений з ТВ як звичайний Bluetooth-пристрій — спершу
   забудьте ТВ у налаштуваннях Bluetooth телефона.
2. У застосунку натисніть **📺 ТВ → Новий телевізор** — телефон стане видимим на 2 хв.
3. На телевізорі: **Налаштування → Пульти й аксесуари → Створити пару з аксесуаром**.
4. Оберіть свій телефон у списку, підтвердьте код на обох екранах.
5. Статус у застосунку стане зеленим «Підключено». Наступного разу підключення автоматичне.

Якщо ТВ не бачить телефон: натисніть **📺 ТВ** і оберіть телевізор зі списку
сполучених — застосунок підключиться сам.

## Обмеження
- Пульт працює, поки застосунок відкритий (у фоні з'єднання розривається).
- Текст — лише латиниця/цифри/знаки (обмеження HID-клавіатури).
- Деякі прошивки OnePlus/OxygenOS обмежують HID-режим; якщо статус «Телефон не підтримує
  режим HID», вимкніть і увімкніть Bluetooth та перезапустіть застосунок.

## Структура
- `HidDescriptor.kt` — опис «клавіатура + пульт» і коди кнопок
- `HidRemote.kt` — реєстрація HID, підключення, надсилання натискань
- `KeyMap.kt` — символи → коди клавіш
- `MainActivity.kt` + `activity_main.xml` — інтерфейс пульта
